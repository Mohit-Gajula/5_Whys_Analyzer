# Contributing to 5 Whys Analyzer

Thanks for your interest in contributing.

5 Whys Analyzer is an open-source root cause analysis toolkit for teams.

## Ways to contribute

- Improve documentation
- Report bugs
- Suggest features
- Add tests
- Improve the Flask app
- Add export formats
- Improve local LLM prompts
- Build integrations for GitHub, Jira, Slack, or Notion

## Pull requests

Before opening a pull request:

1. Keep changes focused.
2. Add or update tests when relevant.
3. Update documentation when behavior changes.
4. Explain why the change matters.
