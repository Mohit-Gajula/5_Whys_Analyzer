# Code of Conduct

## Our pledge

We want this project to be welcoming, respectful, and useful for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent.
- Give helpful feedback.
- Focus discussions on the project and its users.

## Unacceptable behavior

- Harassment or personal attacks
- Discriminatory language
- Trolling or repeated disruption
- Publishing private information without permission
