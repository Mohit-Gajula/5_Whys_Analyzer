# Roadmap

5 Whys Analyzer is being built into a company-ready open-source root cause analysis toolkit.

## Phase 1: Foundation

- Clean project structure
- Strong README
- License
- Contribution guide
- Security policy
- Basic tests
- GitHub issue templates

## Phase 2: Structured RCA workflow

- Problem statement
- Impact
- Timeline
- Five whys
- Root cause
- Contributing factors
- Corrective actions
- Preventive actions
- Owners and due dates

## Phase 3: Exports

- Markdown export
- JSON export
- Slack-ready summary
- Jira-ready summary
- GitHub Issue-ready summary

## Phase 4: Persistence

- SQLite storage
- Saved analyses
- Edit/delete analyses
- Created and updated timestamps

## Phase 5: Deployment

- Dockerfile
- Docker Compose
- Health check endpoint
- Deployment guide
