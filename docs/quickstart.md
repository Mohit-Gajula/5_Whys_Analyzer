# Quickstart

This guide explains how to run 5 Whys Analyzer locally.

## Requirements

- Python 3.10+
- Ollama installed locally
- A local Ollama model such as llama3

## Setup

git clone https://github.com/Mohit-Gajula/5_Whys_Analyzer.git
cd 5_Whys_Analyzer
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

## Run

python app.py

Open http://127.0.0.1:5000
