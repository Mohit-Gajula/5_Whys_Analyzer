# Privacy

5 Whys Analyzer is intended to support privacy-conscious root cause analysis workflows.

## Local-first approach

When configured with Ollama, the tool can run against a local model. This can help teams keep incident details on their own machine or infrastructure.

## Sensitive data

Do not enter sensitive data unless your organization has approved the environment where the tool is running.

## Future privacy goals

- Local-only mode documentation
- Redaction helpers
- Export controls
- Deployment guidance for internal company use
