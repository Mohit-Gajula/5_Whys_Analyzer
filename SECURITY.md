# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Report the issue privately to the project maintainer.

Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix, if available

## Sensitive data warning

Root cause analysis reports may include sensitive operational, customer, infrastructure, or security information.

Do not paste confidential data into this tool unless you are running it in an approved environment and your organization permits that usage.
